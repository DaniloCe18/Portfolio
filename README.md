# Portfolio de Danilo José Cerasa

Portfolio personal de Danilo José Cerasa, Analista en Sistemas y estudiante de Ingeniería en Sistemas. Presento mi perfil, habilidades y proyectos, y estoy pensando para mostrarlo en una búsqueda laboral.

**Sitio publicado:** https://daniloce18.github.io/portfolio/

## Stack

- HTML5 semántico (`header`, `nav`, `main`, `section`, `footer`)
- CSS3 con variables, Grid y Flexbox
- JavaScript sin librerías ni frameworks
- Despliegue en GitHub Pages

## Funcionalidades

- Secciones: Inicio, Sobre mí, Habilidades, Proyectos y Contacto
- Diseño responsive (probado en 360, 768 y 1280 px)
- Modo claro y oscuro, que respeta la preferencia del sistema y se recuerda con `localStorage`
- Animaciones suaves que respetan `prefers-reduced-motion`
- Formulario de contacto con validación de campos
- Accesibilidad básica: enlace para saltar al contenido, `alt` en imágenes, foco visible y navegación con teclado

## Cómo correrlo localmente

No requiere instalar dependencias.

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/DaniloCe18/portfolio.git
   cd portfolio
   ```
2. Abrí `index.html` en el navegador, o usá la extensión **Live Server** de VS Code para verlo con recarga automática.
